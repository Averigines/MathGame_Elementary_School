## Description

This is a mobile game, developed for my bachelor thesis on the topic of digital game-based learning in elementary schools. It's optimized for the use on tablets rather than mobile phones.
The game aims to help students practicing simple arithmatics operations. \
The player plays a fisherman needing to reel in fish which represent different numbers. The player needs to perform simple arithmetics to get from a start number to a goal number by reeling in the correct fish.

## Features

- Different arithmetics options to practice (Addition, Substraction, Multiplication)
- Adaptive difficulty based on students performance
- Dynamic level generation - no predefined levels

## Controls

- Tap above the water to move the boat
- Tap below the water to throw out the fishing hook
- Tap on the hook when it touches a fish to reel it in
